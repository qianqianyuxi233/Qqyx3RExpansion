# Qqyx3RExpansion（qqyx的3r扩展）

Pathfinder: Wrath of the Righteous 的机制类 mod：把一批 D&D 3.5  的内容
（法术、职业、变体、专长、物品）移植进游戏。

## 依赖

| 项 | 要求 |
|---|---|
| 游戏 | Pathfinder: Wrath of the Righteous（Enhanced Edition） |
| Unity Mod Manager | 0.32.4 或更新 |
| **TabletopTweaks-Core** | **必需前置**，未安装时本 mod 不会正常工作 |

## 安装

1. 先用 Unity Mod Manager 安装并启用 **TabletopTweaks-Core**
2. 把 `Qqyx3RExpansion` 文件夹放进 `<游戏目录>\Mods\`
3. 启动游戏，在 UMM 主界面确认「qqyx的3r扩展」已出现并处于启用状态

> 蓝图类改动**必须重启游戏**才会生效 —— UMM 的热重载对蓝图无效。

## 卸载

1. 退出游戏
2. 删除 `<游戏目录>\Mods\Qqyx3RExpansion\` 整个文件夹

> 存档中可能残留本 mod 的蓝图引用，卸载前建议先备份存档。

## 从源码构建

需要 .NET SDK 9.0，以及本机已安装游戏本体。

```powershell
dotnet build Qqyx3RExpansion.slnx -c Debug
```

构建会自动完成三件事：

1. 编译 `Qqyx3RExpansion.csproj`
2. 用 ILRepack 把 `BlueprintCore.dll` 合并进 `Qqyx3RExpansion.dll`
3. 把产物部署到 `<游戏目录>\Mods\Qqyx3RExpansion\`

发布版本（额外在 `bin\` 下生成 `Qqyx3RExpansion-<版本>.zip`）：

```powershell
dotnet build Qqyx3RExpansion.slnx -c Release
```

> **构建前请先关闭游戏**，否则 `Mods\Qqyx3RExpansion\Qqyx3RExpansion.dll` 被占用会导致部署失败。
>
> 请通过 `.slnx` 构建而不是 `.csproj` —— 游戏安装路径由解决方案在构建时自动探测，
> 直接用 `.csproj` 构建会因为找不到游戏路径而失败。
